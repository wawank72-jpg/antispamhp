# AntiSadap Guard (Android Native)

Aplikasi auditor keamanan Android untuk mendeteksi penyadapan berbasis spyware/APK berbahaya dan pengalihan panggilan.

## Cara Mengubah Menjadi File .APK (Tanpa Android Studio)
1. Buat repositori baru di GitHub (misalnya `antisadap-guard`).
2. Unggah seluruh isi folder ini ke repositori tersebut.
3. Buka tab **Actions** di GitHub, pilih workflow **Build AntiSadapGuard APK**, lalu unduh hasil build **AntiSadapGuard-APK** pada bagian Artifacts.
4. Ekstrak file ZIP-nya dan instal `app-debug.apk` di HP Android Anda.
